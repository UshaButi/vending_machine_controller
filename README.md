Vending Machine Controller - Verilog Project

# Objective
A simple vending machine controller implemented in Verilog HDL using a state machine approach.

# Project Contents
- Verilog RTL files
- Testbench
- Simulation waveforms
- Schematic diagrams
- Synthesis report

# Functionality
- Takes input signals representing currency
- Validates the amount
- Processes item selection
- Dispenses the product based on the FSM logic

# Main Files
- main_controller.v
- pulse_sync.v
- config_module.v
- item_selection.v
- currency_input.v
- output_info.v
- vending_machine_top.v
- vending_machine_top_tb.sv
- Output waveform
