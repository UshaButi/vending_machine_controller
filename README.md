## Project Overview
This project implements a **Vending Machine Controller** using **Verilog HDL** based on a **Finite State Machine (FSM)** approach.  
The design simulates the operation of a vending machine by handling currency input, validating the amount, processing item selection, and dispensing the product.

---

## Objective
- To design a vending machine controller using FSM-based logic
- To understand RTL design using Verilog HDL
- To verify functionality through simulation and synthesis

---

## Project Contents
- Verilog RTL files

## Functionality
- Accepts currency input signals
- Validates the inserted amount
- Processes item selection
- Dispenses the selected product based on FSM logic

## Main Files
